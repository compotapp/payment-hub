2. Какие бывают ошибки (по типам)
   Тип ошибки	Пример	Что делать
   Валидация	amount <= 0, user_id пустой	Вернуть ошибку сразу, не трогая БД
   Бизнес-логика	Недостаточно средств, резерв не найден	Вернуть с понятным сообщением
   Конкурентность	OptimisticLockException (version изменился)	Повторить операцию (retry)
   Временная	Таймаут БД, сеть упала	Retry с backoff
   Постоянная	Резерв уже закоммичен, нельзя отменить	Вернуть ошибку без retry
   Системная	БД недоступна, транзакция упала	Retry или fallback
